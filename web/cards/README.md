# BANG! The Duel card artwork

The front-facing card and character images are local copies of the official
artwork published in the
[BANG! The Duel card list](https://bang.dvgiochi.com/cardslist.php?id=10#q_result).

The filenames use the engine's stable card and character keys so the frontend
can render assets directly from API responses. The artwork remains the property
of its respective copyright holders.

The `card_back_*.png` files are original generated artwork used for face-down
Law, Outlaw, and reserve piles in the web interface; they are not official card
backs.
